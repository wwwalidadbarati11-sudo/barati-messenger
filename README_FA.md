# پروژه براتی – نسخه نمایشی اندروید ۰.۱

این پروژه یک نمونه اولیه بومی اندروید با Kotlin و Jetpack Compose است.

## امکانات فعلی
- صفحه اصلی با هویت بصری BARATI
- فهرست گفتگوهای نمونه
- جستجوی محلی در گفتگوهای نمونه
- تب‌های گفتگو، تماس، استوری، کانال و پروفایل
- صفحات جای‌نگهدار برای بخش‌هایی که در نسخه بعدی پیاده‌سازی می‌شوند

## مواردی که هنوز واقعی نیستند
این نسخه به سرور وصل نیست. ورود با شماره موبایل، ارسال پیام واقعی، تماس صوتی/تصویری، آپلود رسانه، استوری آنلاین و کانال‌ها هنوز پیاده‌سازی نشده‌اند.

## ساخت APK
1. این پوشه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync کامل شود.
3. از منوی Build گزینه Build APK(s) را انتخاب کنید.
4. فایل debug APK معمولاً در `app/build/outputs/apk/debug/` ساخته می‌شود.

## شناسه برنامه
`com.barati.messenger`

## نکته
برای ساخت APK به محیط سازگار با Android Gradle Plugin 8.7.3، JDK 17 و Android SDK 35 نیاز است.
